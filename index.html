Construcción de prompts

25 pts

Diseña un prompt para resolver el caso. La app valora elementos observables del prompt: contexto, objetivo, audiencia, datos, restricciones, formato y criterio de calidad.

Caso: Una cadena regional de cafeterías quiere aumentar la recompra de clientes de 20–35 años. Cuenta con tickets de compra, frecuencia de visita, productos comprados y respuestas de una encuesta de satisfacción. Debes pedir a una IA apoyo para proponer una estrategia de retención, evitando inventar datos.
